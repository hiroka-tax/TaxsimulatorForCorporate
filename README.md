# 法人税・消費税シミュレーター

売上と経費を入力するだけで、法人税等・消費税の概算納税額を手軽に確認できるWebツールです。

## 概要

税理士向け・経営者向けに、法人の税負担をざっくり把握するためのシミュレーターです。  
ブラウザ上で完結するため、インストール不要でそのままご利用いただけます。

## 主な機能

- 売上・経費の入力 — 売上金額と経費金額を入力し、利益率／経費率を自動計算して表示

- 事業年度の月数 — 1〜12か月を選択（既定12）。短期事業年度の場合、軽減税率の限度額・事業税の区分・均等割・防衛特別法人税の基礎控除を月数按分

- 法人税等の計算 — 法人税・地方法人税・事業税・特別法人事業税・住民税（法人税割・均等割）を自動計算

- 事業税の区分計算 — 所得400万円以下（3.5%）・400万円超800万円以下（5.3%）・800万円超（7.0%）の3区分で計算（閾値は月数按分）

- 消費税の計算 — 簡易課税（みなし仕入率選択）・本則課税（課税仕入れ額入力）・2割特例に対応。消費税（国税）と地方消費税を分離表示

- 中間納付の控除 — 法人税等・消費税それぞれの中間納付額を入力し、期末納付額を算出

- 繰越欠損金の控除 — 繰越欠損金を入力することで課税所得を調整

- 別表四の調整 — 加算・減算をそれぞれ入力し課税所得に反映（例：事業税の損金算入（前期確定額））

- 翌期の中間納付見込み — 前期税額の年換算ベースで判定（法人税 年換算20万円超・消費税 年換算48万円超）し、アラート表示と見込み納付額を自動算出

## 使い方

1. index.html をブラウザで開く

2. 事業年度の月数を選択する（通常は12か月。設立初年度や決算期変更などの短期事業年度は該当月数を選択）

3. 売上（円）を入力する

4. 経費（円）を入力する（利益率・経費率は自動表示）

5. 繰越欠損金・中間納付額など該当する項目を入力する

6. 別表四の加算・減算がある場合は入力する

7. 消費税の計算方法（簡易課税・本則課税・2割特例）を選択する

8. 簡易課税の場合はみなし仕入率を、本則課税の場合は課税仕入れ額を入力する

9. 「計算結果」欄に各税目の概算額が自動表示される

## 税率・計算の前提

| 項目 | 税率・内容 |

|------|-----------|

| 法人税（課税所得800万円以下） | 15% |

| 法人税（課税所得800万円超） | 23.2% |

| 地方法人税 | 法人税額 × 10.3% |

| 事業税（所得割・400万円以下） | 3.5% |

| 事業税（所得割・400万円超800万円以下） | 5.3% |

| 事業税（所得割・800万円超） | 7.0% |

| 特別法人事業税 | 事業税額 × 37% |

| 住民税（法人税割） | 法人税額 × 7% |

| 住民税（均等割） | 70,000円（年額・100円未満切捨て） |

| 防衛特別法人税 | （法人税額 − 基礎控除500万円）× 4% |

| 消費税（簡易課税） | 売上消費税額 ×（1 − みなし仕入率） |

| 消費税（本則課税） | 売上消費税額 − 課税仕入れ消費税額 |

| 消費税（2割特例） | 売上消費税額 × 20% |

| 地方消費税 | 消費税額（国税）× 22/78 |

### 短期事業年度の月数按分

事業年度が12か月未満の場合、以下の年額基準を「年額 × 月数 ÷ 12」で按分します。

| 項目 | 年額基準 | 按分例（6か月） |

|------|---------|----------------|

| 法人税 軽減税率（15%）の限度額 | 800万円 | 400万円 |

| 事業税 区分の閾値 | 400万円 / 800万円 | 200万円 / 400万円 |

| 住民税 均等割 | 70,000円 | 35,000円 |

| 防衛特別法人税 基礎控除 | 500万円 | 250万円 |

| 中間申告の判定 | 前期税額の年換算（法人税20万円／消費税48万円）で判定 | — |

> 注意: 本ツールは概算計算を目的としています。事業税・住民税は東京都・資本金1億円以下（外形標準課税対象外）の標準税率を前提としており、実際の税額は自治体・法人区分により異なります。正確な税額については税理士にご相談ください。
